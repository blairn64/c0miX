# Roadmap

## Foundation

- Define the canonical issue and series model.
- Import a controlled source dataset.
- Store ownership and reading state separately from imported metadata.

## Core features

- Series and issue search
- Canonical run ordering
- Missing-issue detection
- Ownership/read status
- Variant and reprint relationships
- Run completion summaries

## Engineering improvements

- API tests for ordering and gap detection
- Repeatable import pipeline
- Schema migration strategy
- Docker-based local development
- CI for tests and linting

## Portfolio presentation

The project should include an architecture diagram, example dataset, setup instructions, screenshots generated from synthetic/personal data only, and notes explaining the key modelling decisions.
